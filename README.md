# Amazon Clone DevOps Project

## Project Overview

This project demonstrates a complete CI/CD workflow by deploying an Amazon Clone web application on AWS EC2 using Docker and Jenkins.

## Architecture

GitHub → Jenkins → Docker → AWS EC2

## Technologies Used

- Linux
- Git & GitHub
- Docker
- Jenkins
- AWS EC2
- HTML
- CSS

## Project Structure

```
Amazon-Clone-Devops/
├── Dockerfile
├── Jenkinsfile
├── deploy.sh
├── index.html
├── style.css
├── images/
├── README.md
└── .gitignore
```

## Features

- Dockerized web application
- Automated deployment using Jenkins
- Hosted on AWS EC2
- Version controlled with Git and GitHub
